## 📌 Sobre
Este é um repositório organizado e mantido por **thalissonsenai-boop**. 
Jogo educativo de matemática com temática de doces.

## 🚀 Funcionalidades
- Operações matemáticas básicas
- Sistema de pontuação
- Interface lúdica e infantil

## 🛠️ Tecnologias
Este projeto utiliza:
- **JavaScript, HTML, CSS**

## 💻 Como Rodar
1. Clone este repositório:
   ```bash
   git clone https://github.com/thalissonsenai-boop/Candy-Math.git
   ```
2. Abra o diretório do projeto:
   ```bash
   cd Candy-Math
   ```
3. Abra o `index.html` diretamente no seu navegador.
